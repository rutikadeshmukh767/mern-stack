# Simple Task Manager

A small, responsive React + Vite task manager.

## Features
- Add tasks
- Mark tasks as complete or active
- Filter all, active, and completed tasks
- Delete tasks
- Clear completed tasks
- Automatically save tasks in browser local storage

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the localhost URL printed by Vite.

To verify a production build, run `npm run build`.
